# TDS_V3.1

Written in Python 3.13.2<br/>
Displays Data to the Console<br/>
Data Stored in V3 Setup using CSV Files<br/>
Results saved to a Folder called 'Results' that the User will have to create themselves, as well as the Season Sub-Folder<br/>

Balance of Performance Folders for each Series use the Series **Code** for the Folder Name.<br/>

Use 'command.txt' if you decide to run the program via the Command Line / Console<br/>
If you choose to run the program via a Code Editor (such as VSCode or PyCharm), then you don't need the file, and it can be safely deleted.
